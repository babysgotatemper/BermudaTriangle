Інтерактивна освітня веб-сторінка про Бермудський трикутник для дітей.

## 📋 Вміст

- **index.html** — Головна інтерактивна сторінка про Бермудський трикутник
  - Про що це місце
  - Де розташування
  - Історія назви
  - Які кораблі/літаки зникли
  - Теорії та факти
  - Інтерактивна карта

- **origin.html** — Історія створення проєкту
  - Оригінальний запит від Артема
  - Як виник проект

### OG Image

**ВАЖЛИВО**: Потрібно створити `og-image.png` (розміри 1200×630px)

Варіанти:
1. **Онлайн-конвертер**: https://cloudconvert.com/svg-to-png (завантажте og-image.svg)
2. **ImageMagick**: `convert -density 300 og-image.svg -resize 1200x630 og-image.png`
3. **Vercel OG**: Якщо є Pro план

## 📱 Тестування Telegram Preview

Після створення `og-image.png`:
1. Вставте посилання в Telegram
